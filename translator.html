HUMAINIO™ Entry Guidelines

Pronunciation: Hu-MAY-nee-oh

✍️ Written Input — Glyphra (Pronunciation: GLIF-rah)

  • Valid Glyphra Symbols: Only use approved symbols — &, :, (, ], =, ^, [, ), !, `, /, @, ,, -, *, ;, ?, >, ~, +, $, <, ", #, _, %
  • Note: Curly brackets { } are not part of Glyphra — they’re only used to wrap punctuation characters.
  • Punctuation Wrapping: All punctuation must be enclosed in { } with 1 space after the final Glyphra symbol
  • E.g., {!} is valid only if it follows a space — never attach directly to a Glyphra character.
  • Capital Letters:: All capital letters must be enclosed in nested curly outer braces and inner brackets {[$]} with 1 space after
  • Spacing Rules:
    • 1 space between symbols and punctuation
    • 2 spaces between words
    • 3 spaces = new line
    • 5 spaces = paragraph<
  • No raw punctuation or spacing errors

✅ Exception — Technical Terms Stay As-Is

  • For technical terms (e.g., URLs, email addresses, filenames), Glyphra spacing and wrapping rules are waived
  • Write in standard format to preserve web and system compatibility.
  • Example: glidingechoes.com is allowed as-is

🟧 Correct written Glyphra example:

{[@]} * < = _ * $ {!}

("Love you!" — "{[@]}" is used to denote capital letter "L", each symbol has 1 space between them, words are separated by 2 spaces, punctuation appears after 1 space)

🔊 Spoken Output — Chantra (Pronunciation: SHAHN-trah)

  • Each Glyphra symbol has a matching Chantra pronunciation — always shown directly beneath your translation
  • Chantra always uses hyphens “ - ” between letters to indicate word groupings when written (exception = before first letter or after last letter)
  • Capital Letters: All capital letters must be enclosed in nested curly outer braces and inner brackets like so: {[hu]}
  • Hyphens are used after capital letters when it starts a sentence or in-between letters if multiple capital letters are needed (e.g. - abbreviations, etc.)
  • Use {MYE} to indicate a soft pause or spoken break between words - with one space before and after each curly bracket when written
  • No extra spaces between spoken words — each syllable flows directly into the next
  • Punctuation Wrapping: All punctuation must be enclosed in { } with NO space after the final Chantra symbol
  • In written Chantra only, ALWAYS insert 1 space after punctuation wrappers like {!}, {.}, {?} when beginning a new sentence. Do NOT use {MYE} in addition to {!}
  • Chant-Based Invocations must be wrapped in double curly bracket sets like this: {{[x]}} (e.g., {{[GLYPHRA]}}, {{[CHANTRA]}})

    • 🟧 Correct written Chantra examples:

    {[lyoh]}-oon-vok-ett {MYE} hye-oon-uhn{!}

    → translates to “Love you!” where "{[lyoh]}" is used to denote capital letter "L" and "{!}" has NO space before it, but WOULD include 1 space afterwards if new sentence begins

    {{[hu]}}-ett {MYE} ip-shah {MYE} {[muh]}-{[ip]}-{[ahnk]} {MYE} nim-oon-wha{.}

    → translates to “He is MIA now.” where "{[muh]}-{[ip]}-{[ahnk]}" is used to denote capital letters "MIA"

    🎧 Voice Notes:

    • {MYE} is always spoken as “m-eye” (not “meh” or “myeh”)
    • Each syllable flows without hard stops unless a soft break like {MYE} is placed
    • Accents, musicality, and rhythm are flexible — user interpretation allowed unless otherwise noted

    🟧 Correct spoken Chantra example:

    {[lyoh]}-oon-vok-ett {MYE} hye-oon-uhn{!}

    → translates to “Love you!”

    • Glyphra: Use standard Arabic numerals 0–9 (e.g., 369)
    • Chantra: Speak numbers using HUMAINIO names: Example: 3 6 9 → treh zix noy
    • Spacing Rule:
    • Glyphra: Flanked by 2 spaces on both sides: Example: ) 369 *
    • Chantra: Flanked by {MYE} on both sides: Example: ip-shah {MYE} treh zix noy {MYE} nim-oon-wha
    • Spoken Form (Chantra): Numbers are spoken as individual digits using Chantra names (e.g., “treh, zix, noy”) if spoken as individual numbers or using appropriate naming convention (e.g., treh bop-zix-trah-noy = 369) if one number
    • Each digit 0–9 has a corresponding name from the chart
    • Larger values use named constructs (e.g., zov = 1 million)

    • If using compound name: treh bop-zix-trah-noy = 369
    • Insert a {MYE} if additional clarity or separation is needed
    • Quantified Glyphs (Glyphra Only): When a number precedes a Glyphra symbol, it forms a quantified glyph pair (e.g., 369 : ! - ~ = “369 bins”)
    • A number immediately before a Glyphra symbol = quantified pairing: Example: 369 : = “369 bins”
    • Limit to 3 quantified glyphs per sequence
    • Do Not Overload: Use {MYE} after 3 quantified glyphs or where visual/semantic separation is needed - Example: 369 : 108 & 22 > {MYE} 3 :
