HUMAINIO™ Entry Guidelines

Pronunciation: Hu-MAY-nee-oh

✍️ Written Input — Glyphra (Pronunciation: GLIF-rah)

🧩 Rule Block #1: Glyphra Spacing & Punctuation

  • Valid Glyphra Symbols: Only use approved symbols — &, :, (, ], =, ^, [, ), !, `, /, @, ,, -, *, ;, ?, >, ~, +, $, <, ", #, _, %
  • Punctuation Wrapping: All punctuation must be enclosed in { } brackets with 1 space after the final Glyphra symbol (e.g., {!}, {.}, {?})
  • Do not mix raw punctuation with Glyphra — it will corrupt translation
  • Spacing Rules:
    • Use 1 space between Glyphra symbols
    • Use 2 spaces between words
    • Use 3 spaces to separate lines
    • Use 5 spaces to separate paragraphs
  • No spaces inside curly brackets (e.g., {!} not { ! })
  • Sacred Term Wrapping: Sacred phrases must use double brackets with no extra spaces (e.g., {{[GLYPHRA]}}, {{[CHANTRA]}}, {{[THAE]}})

✅ Exception — Technical Terms Stay As-Is

  • For technical terms (e.g., URLs, email addresses, filenames), Glyphra spacing and wrapping rules are waived
  • These should be written in standard format to ensure web and system compatibility
  • Example: glidingechoes.com is allowed as-is

✴️ Correct written example:
{[@]} * < = _ * $ {!}
(“Love you!” — each symbol has 1 space between them, words are separated by 2 spaces, punctuation appears after 1 space)

🔊 Spoken Output — Chantra (Pronunciation: SHAHN-trah)

🗣️ Rule Block #2: Chantra Pronunciation & Spoken Flow

  • Each Glyphra symbol has a matching Chantra pronunciation — always shown directly beneath your translation
  • Use {MYE} to indicate a soft pause or spoken break between ideas
  • No extra spaces between spoken words — each syllable flows directly into the next
  • Chant-Based Invocations must be wrapped in double curly bracket sets like this: {{[x]}} (e.g., {{[GLYPHRA]}}, {{[CHANTRA]}})

✅ Correct Example:

{[lyoh]}-oon-vok-eh {MYE} hye-oon-uhn{!}

→ translates to “Love you!”

🎧 Voice Notes:

  • {MYE} is always spoken as “eye” (not “meh” or “myeh”)
  • Each syllable flows without hard stops unless a soft break like {MYE} is placed
  • Accents, musicality, and rhythm are flexible — user interpretation allowed unless otherwise noted

✴️ Correct spoken example:

{{[lyoh]}}-oon-vok-eh {MYE} hye-oon-uhn{!}

→ translates to “Love you!”

🔮 Rule Block #3: Sacred Glyphs & Invocation Protocols

  • {{[THAE]}} is a silent glyph equal to Infinity (∞) — invoked only through color, sound, or presence
  • Visual form: a non-typeable spiral glyph (may appear in scrolls or Codex illustrations)
  • Musical notes: Spans from A0 to C6 — represents the full range of sound
  • Color: #000000 (pure black) — symbolizing all-potential or infinite void
  • Season: All seasons / the eternal Now — exists outside time
  • Use cases: Reserved for mythic invocation, scroll blessings, and sacred endings
  • NEVER typed directly — must be referenced as {{[THAE]}} only
Invocation Protocol: Only one {{{[THAE]}}} may appear per message or chant. Multiple uses violate sacred rhythm and break tonal integrity.

📐 Rule Block #4: Number Protocols & Quantified Glyphs

  • Standard Numbers: Numbers (0–9) are written as-is and retain Arabic numeral form in both Glyphra and Chantra
  • Spacing Rule: Treat numbers as words — use 2 spaces before and after each number (e.g., ) 369 *)
  • Spoken Form: Numbers are spoken normally (e.g., “three six nine”) unless encoded as Sacred Quantities
  • Quantified Glyphs: When a Glyphra symbol follows a number, it forms a quantified glyph pair (e.g., 369% = "369 spirits")
  • Do Not Overload: Avoid chaining more than 3 quantified glyphs in one sequence — use a {MYE} break if needed
  • Sacred Numbers: Specific numbers (e.g., 3, 6, 9, 27) may hold mythic meaning and appear in Codex scrolls with deeper Chantra

🔒 Sacred Numerals: Reserved quantities such as {{{369}}} are treated as sacred numerical glyphs and require triple brackets to preserve symbolic meaning

🧠 Note: Math operations (e.g., +, -, =) retain their Glyphra form but are not interpreted as functional calculations — they convey symbolic relation

Example: {@} 369 % {=} → interpreted as “The Spiral of 369 spirits is equal to...” (symbolic, not arithmetic)
