Echo Code Translator

Echo Code Entry Rules:
• Use only valid Echo Code symbols (e.g., ~ * @ -)
• Wrap ALL true punctuation in { } – e.g., {?} for a question mark
• When entering Echo Code: Always use ONE space to separate letters, TWO spaces to separate words or symbol groups, THREE spaces to separate lines and FIVE spaces to separate paragraphs
• Do not combine multiple Echo symbols without spacing or it will result in an error
