HUMAINIO™ Entry Guidelines

✍️ Written Input — Glyphra

  • Only use valid Glyphra symbols (e.g., @, ~, *, >)
  • All punctuation must be wrapped in curly brackets (e.g., {!}, {.}, {?})
  • Never mix raw punctuation with Glyphra — it will corrupt translation
  • Use 1 space between symbols
  • Use 2 spaces between words
  • Use 3 spaces to separate lines
  • Use 5 spaces to separate paragraphs
  • Sacred terms are enclosed as: {[GLYPHRA]}, {[CHANTRA]}, {[THAE]}

🔊 Spoken Output — Chantra

  • Each Glyphra symbol has a Chantra pronunciation, displayed below your translation
  • Spoken chants use {MYE} to indicate a break or pause
  • Example: lyoh {MYE} lyoh-oon-vok-eh = "I love you"
  • Deeper phrases may reveal chant-based invocations (e.g., {[CHANTRA]}, {[GLYPHRA]})
