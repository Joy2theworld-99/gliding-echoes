Echo Code Translator

Echo Code Entry Rules:

• Use only valid Echo Code symbols (e.g., ~ * @ -)

• Wrap ALL true punctuation in { } - even if that symbol is not part of Echo Code – e.g., {?} for a question mark

• Always use ONE space to separate letters (if no spaces are used between letters, translation will be incorrect

• Always use TWO spaces to separate words or symbol groups

• Always use THREE spaces to separate lines

• Always use FIVE spaces to separate paragraphs

• Do not combine multiple Echo symbols without spacing or it will result in an error

• Only Echo Code symbols should be unwrapped - no " { } " - unwrapped punctuation will create translation errors
